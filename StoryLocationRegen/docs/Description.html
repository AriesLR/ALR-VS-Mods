Description

Allows you to set locations to regenerate on a 7-14 in-game day timer. Supports multiple locations.

Requirements
  • ImGui
  • ToastLib
Commands
  • /storylocregen set - Sets the center of the regen radius to the player's current position.
    • Usage: /storylocregen set <locationName> <chunkRadius>
  • /storylocregen regen - Starts the regen process manually with the regular 15 minute warning.
    • Usage: /storylocregen regen <locationName>
  • /storylocregen forceregen - Starts the regen process manually with a 1 minute warning.
    • Usage: /storylocregen forceregen <locationName>
  • /storylocregen delete - Deletes a saved location and cancels any scheduled regen.
    • Usage: /storylocregen delete <locationName>
  • /storylocregen list - Shows the list of currently set regen locations.
    • Usage: /storylocregen list
Known Issues
  • Any land claims within the regen radius can and will be regenerated. This can remove hours of progress so be very careful while using this mod. Make sure there are no bases anywhere within the regen radius for your set location(s).
