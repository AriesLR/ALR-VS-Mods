Description

Claim Flight allows players with build permissions for a land claim to use creative-like flight.

Requirements
  • ImGui
  • ToastLib
Controls
  • Up Arrow — Land Claim Fly Mode On/Off
Compatibility

The mod should be compatible with almost every mod, the only things it might struggle with are any land claim mods that don't use the vanilla land claiming system.

Known Issues
  • Very rarely you will still take minimal fall damage when touching the ground while flying, this is extremely rare and probably not worth fixing.
